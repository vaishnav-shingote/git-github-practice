# Day 4 - Merging

## What is Merge?

Combining changes from different braches

## Types of Merge:

### 1. Fast-Forward

- Happens when no parallel commits
- Simple and clean

### 2. Normal Merge

- Happens when branches diverge
- Creates a merge commit

## Commands:

git merge ---> combine branches
git log ---> view history

## Key Concept:

Multiple developers work on branches and merge into main.
