# Day 6 - GitHub & Remote Workflow

## What is Remote Repository?

A remote repository is a version of the project stored on GitHub.

## Local vs Remote

Local ---> Your computer
Remote ---> GitHub server

## Important Commands

git remote add origin ---> connect repo
git push ---> upload code
git pull ---> download latest changes
git clone ---> Copy repository

## Workflow

1. Clone repository
2. Make changes
3. git add
4. git commit
5. git push
6. git pull before next work

## Example

Developer A pushes code
Developer B runs git pull to get updates

## Key Learning

-GitHub is used for collaboration
-ALways pull before working
-Push after completing changes
